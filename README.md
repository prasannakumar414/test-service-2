# test-service-2

A minimal JavaScript library that exports one function:

```js
import { greet } from "test-service-2";
console.log(greet("Prasanna")); // Hello, Prasanna!
```

Used by [test-service-1](https://github.com/prasannakumar414/test-service-1). The app declares this repository as a Git dependency tracking its master branch.

Requires Node.js 18 or newer. No third-party dependencies or build step.
